# 搞文件 V1.03

全新升级 LaTeX 模块，全面对齐并融入现代化原生 LaTeX 编辑器体验：

- **智能主文件与魔术注释**：支持识别 `% !TeX root = ...` 魔术指令，自动解析并指定工程编译根文件；支持在顶部菜单随时切换主文件与当前文件。
- **文档结构与浮动体大纲导航**：左侧折叠面板提取篇、章、节、子节（`\part`、`\chapter`、`\section`、`\subsection`、`\subsubsection`）及插图（`figure`）、表格（`table`）、公式（`equation`）、标签（`\label`）与文献引用（BibTeX / `\bibitem`），点击任意大纲条目即刻平滑跳转至对应源码行。
- **上下文感知智能代码补全**：
  - 输入反斜杠 `\` 自动列出常用 LaTeX 命令；
  - 输入 `\begin{` 自动列出常用环境，选定后自动配对闭合 `\end{...}` 并将光标置于环境内部；
  - 输入 `\ref{` / `\eqref{` 自动联想当前文档与工程中定义的所有标签；
  - 输入 `\cite{` 自动联想所有文献引用键；
  - 输入 `\usepackage{` 自动联想常用宏包。
- **结构化编译诊断与点击跳转**：编译日志全面结构化为错误（Error）、警告（Warning）与提示（Info），提取对应文件名和具体行号；点击任意诊断项直接在编辑区高亮选中出错行。
- **SyncTeX 双向定位**：
  - **正向定位**：光标所在行一键在预览 PDF 中定位并聚焦（Forward SyncTeX）；
  - **反向定位**：在 PDF 预览区按住 `⌘` 点击任意页面内容，自动调用本地 SyncTeX 反向查找并跳转定位至对应源码行（Inverse SyncTeX）。
- **增强型 PDF 预览与快捷工具条**：
  - PDF 顶部提供放大、缩小、100%、自适应宽度（Fit Width）与自适应页面（Fit Page）控制，重构编译时无缝保持阅读器位置；
  - 顶部增加公式（分式、根号、求和、积分、矩阵、方程组）、常用环境（itemize, enumerate, table, figure, align）与文本样式快捷插入菜单。

版本 **1.03 / build 4**。适用于 Apple Silicon、macOS 14 及以上；本地签名，未进行 Apple 公证。
Release 提供 DMG 和 SHA256 校验文件。程序与源码严格排除用户个人文档、便笺正文、私有附件、设置及安全备份。
