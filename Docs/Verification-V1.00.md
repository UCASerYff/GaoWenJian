# V1.00 验证记录

环境：2026-10-08，Apple Silicon macOS，Swift 6.4（Swift 5 语言模式），部署目标 macOS 14。使用隔离临时文档和资料目录，未修改用户真实文档。

已通过的自动验证：

- CSV/TSV 引号、内嵌换行、CRLF、Unicode 与前导零往返。
- 覆盖前历史快照逐字节读回；外部修改/删除阻止覆盖；损坏工作区和恢复文件不覆盖；恢复为空文本仍显示未保存。
- Word XML 转义、段落样式、换行/制表符、未知对象和附件保留；Excel 基础公式重算、跨表、循环/错误、未知缓存、稀疏单元格、重复保存；PPT 文字、页、文本框和位置往返。
- Office 恢复包、上一份副本、原件绑定、摘要冲突、损坏字节保留与精确丢弃。
- PDF 实际批注位置、表单持久化、文字/便签、撤销重做、旋转裁剪、提取/合并/排序/删除、恢复与外部修改保护。
- Markdown 113 个原文保真断言；真实 WKWebView 的本地加载、图片、远程资源阻止、公式、Mermaid、脚注、表格、大纲、源码模式/块编辑、HTML 和 1 页 A4 PDF 导出。
- RTF 20 个格式、恢复、冲突、损坏草稿与保存保护断言。
- 图标 108,000 个背景像素保持完全相同的不透明中性灰。字形独立居中绘制，画布不裁切。
- 安装脚本隔离模拟：初装、更新、附件/设置备份、回滚、旧程序精确清理、错误 Bundle ID、不可读取资料与损坏备份阻止操作。

已通过的实际程序验证：

- 首屏与多标签界面；Markdown 源码修改/保存；Word 修改后切换 Markdown 再返回仍保留修改。
- 原生 Word、Excel、PPT 修改保存后读取真实 Office XML，内容符合 GUI 修改；Excel B2 改为 25 后依赖 B3 的公式缓存同步变为 25。
- PDF 表单编辑保存；窗口关闭时出现未保存保护，返回编辑可继续保存。
- 应用内随附 Tectonic 和独立临时缓存均在 `--only-cached --untrusted` 模式成功编译中文/数学示例；生成真实 PDF、日志和 SyncTeX 文件，未联网下载宏包。
- 新建三种 Office 文件经本机 LibreOffice 排版导出 PDF，并检查中文内容与版面。
- PDF 画布在实际窗口扩展到可用高度，初始缩放符合适合窗口值，初始第 1 页；手动缩放在调整窗口后保持。

最终发行包须通过 Info.plist 版本检查、本地签名检查、DMG 完整性与 SHA256 校验。安装后的 GUI 验收及回滚状态记录在 `安全备份/安装-*/manifest.json`。

功能边界见 README 和 OfficeSupport。当前为本地基础工作台，并未宣称完整替代 Office、Typora 或 Overleaf。数字签名、加密 PDF、复杂公式/对象等应按界面和说明所列范围处理。
