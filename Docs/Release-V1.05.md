- 远程仓库：`https://github.com/UCASerYff/GaoWenJian`

## 更新概览

本版本正式接入跨应用文档交接契约 GaoAction V1（任务04）：
1. **纯本地与透明来源**：
   - 搞文件始终坚持无账户、本机离线、无 AI 原则；
   - 明确声明 OCR 文字识别由外部搞系列应用“搞截图”（`com.gaoseries.GaoJieTu`）负责，搞文件作为编辑工作台接收产物，不借机宣称自研 OCR 引擎；
   - 来源元数据（原件摘要、页码、识别引擎/版本、语言、坐标系与置信度）安全保存在本地 `Exchange/Origins`，不与原文档文本混淆。

2. **接收 OCR 识别文字 (`documents.newText`)**：
   - 接收后新建未保存文档，保留当前已打开的所有标签、光标位置、未保存内容与自动恢复稿；
   - 绝不静默覆盖用户当前编辑文件，绝不悄悄自动落盘。

3. **核验与接收可搜索 PDF (`documents.open`)**：
   - 外部可搜索 PDF 产物必须通过 `PDFHandoffVerifier` 核验其页数、页面旋转、MediaBox/CropBox 与文字检索/选取的一致性；
   - 作为新标签打开，完整保留原 PDF。禁止将无文字层的图片 PDF 或旁注文字伪称为可搜索 PDF。

4. **接收搞整理选中文档**：
   - 仅打开用户在搞整理中明确选中的文件或交接副本；
   - 不读取外部索引库，不申请全局磁盘访问权限，接收端独立核验文件存在性与读取权限。

5. **识别扫描件/图片 (OCR) 入口**：
   - 在首页核心卡片、PDF 阅读工具栏、图片查看器及菜单栏提供明确的“识别扫描件/图片 (OCR)”入口；
   - 自动检测搞截图 `ocr.files` 能力，未保存的当前 PDF 提供“导出副本”与“发送原件”选项；
   - 当提供方未安装时，提供清晰友好的提示，并提供“在访达中显示”与“导出副本…”选项，不自动下载外部依赖。

6. **敏感路径与攻击防御**：
   - 严格阻断交接请求访问应用内部资料库、历史备份目录、系统偏好设置或钥匙串路径；
   - 限制单份交接文档上限为 256 MiB，正文为 8 MiB，彻底防范符号链接劫持、路径穿越、Zip 炸弹与外部 XML 实体注入。
