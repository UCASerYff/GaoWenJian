# V1.03 验证记录

版本 **1.03 / build 4**。全面增强 LaTeX 模块，包含智能主文件与 `% !TeX root = ...` 魔术指令解析、章节与图表大纲导航、上下文感知自动补全（命令、环境配对、标签、文献、宏包）、结构化诊断与错误点击精准跳转、SyncTeX 双向定位（Forward/Inverse）、增强型 PDF 缩放与快捷公式工具条。

1. **测试回归**：
   - `Scripts/test.sh` 退出码 0，包含 45 项全新针对 LaTeX 索引、自动补全、诊断解析与根指令的单元断言，以及原有文件保存/恢复、Office 往返、PDF 批注、便笺富文本与附件、Markdown 核心、RTF 恢复与图标规范全量通过。
   - `python3 Tests/InstallTests.py` 退出码 0，包含安装事务、备份核验、配置校验、回滚机制和精确清理全量通过。

2. **功能核验**：
   - 结构大纲（`LaTeXIndexer`）：精确提取各级章节、浮动体及标题，点击任意节点平滑跳转至对应源码行；
   - 自动补全（`LaTeXCompletion`）：输入 `\`、`\begin{`、`\ref{`、`\cite{`、`\usepackage{` 弹出候选列表，环境自动闭合 `\end{...}` 并合理定位光标；
   - 诊断与定位（`LaTeXDiagnosticParser`）：`-file-line-error` 及 Tectonic 错误日志结构化为错误与警告列表，点击条目自动高亮选中错误行；
   - SyncTeX 双向跳转（`SyncTeXService`）：正向一键定位 PDF 视口，反向 ⌘-点击 PDF 内容反向查出源码行号并高亮选中；
   - PDF 预览：提供放大、缩小、100%、适应宽度与适应页面控制，重构编译时保持已有阅读进度。

3. **安全与发布**：
   - 安装采用安全事务流水线，预先生成安全备份；
   - 正式安装后主窗口标题更新为“搞文件 V1.03”；
   - 校验成功后精确清理旧版程序与旧版安装包；
   - 排除任何个人隐私、便笺或安全备份后同步推送至 GitHub 仓库。
