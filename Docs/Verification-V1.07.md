# 搞文件 V1.07 验证记录

版本：V1.07 / build 8。记录日期：2026-10-17。

本次按用户明确授权，启动已安装应用执行指定的 PDF 表单、OCR 与文档交接专项验收。未运行通用冒烟测试。测试使用自建文档和隔离资料，不使用真实文档作修改测试。下文分别记录实现、实际界面证据、无窗口验证与尚未验收项目，测试数量不表示跨应用流程均已完成。

## 本次实现

- PDF 表单以真实 widget 值变化记录 dirty 和恢复稿，结合值轮询及公开 AppKit 编辑通知；进入字段本身不再算作修改。保存、交接、关闭和退出同步提交当前输入，提交失败时停止离开或序列化。
- 画布表单修改进入 PDF 撤销/重做记录；交接采用真实编辑器模型的当前快照，保留未保存批注、字段值、撤销记录及原件摘要冲突保护。纯导出且字段未变化时不重写已有恢复稿。
- OCR 可以选择文字、Markdown、JSON 和可搜索 PDF。结果通过原请求、输入/输出 ID 与摘要关联；JSON 正文额外核对来源、字节数、页序和逐页状态，图片来源的 PDF 增加画面/页面对照。核验不代表 OCR 文字准确率。
- 补充应用实际打开交接包的 URL 回调；结果明确接收为新未保存文字标签或独立 PDF 副本，不覆盖已有编辑文档。
- 来源栏展示声明来源、对应输入、逐页失败原因和核验限制。来源 bundle ID 不是身份认证。选择原件时需明确告知保存会写回原文件。
- 新增“导出编辑副本…”，供本人在研究端重新导入。文字导出当前 UTF-8 内容；PDF 明确选择当前编辑版本或已保存版本；Office 保持只读，副本按字节保留。目标覆盖须先核验并保留历史快照，原件及入站副本受保护。
- `files.choose` 增加原件/副本选择和本端文件面板重新授权；提供方缺失时明确提示不可用。LaTeX、Markdown 核心、Office 只读定位及便笺附加工具定位保持。

“可搜索 PDF 基本文字层核验通过”表示本应用执行了来源关联、页面/画面与文字层检查，不表示已人工逐字校对、保证全部 OCR 文本正确或证明来源身份。实际 `partial` 与接收取消分别记录，没有合并为全部成功。
