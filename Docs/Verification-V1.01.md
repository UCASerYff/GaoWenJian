## 本轮代码审阅已修正的边界

便笺中心和浮窗切换、收起、回收站、导出及 Markdown 副本操作在销毁或读取编辑器之前提交输入法组合文本。跨窗口同步正文时清除旧撤销范围，避免对另一份正文执行错位撤销。

根窗口保存和便笺快捷键按当前编辑窗口路由；保存便笺先提交编辑，编译及另存动作再次检查当前是否便笺窗口。关闭浮窗只隐藏，保存失败保留窗口与内存修改；回收站保留正文、格式和附件。

这些为源码审阅结果，不能替代实际窗口验收。V1.00 原有能力的验证历史见 `Verification-V1.00.md`。

## 已通过：便笺存储与迁移独立测试

本轮独立 Swift 存储测试通过 72 个断言。使用隔离随机临时目录；正文和附件为生成的测试资料，不读取系统便笺数据库。

已验证富文本及附件往返、正文编辑为空、元数据/默认样式、回收站恢复、TXT/RTF/RTFD 导入导出与目标替换保护、外部修改/删除和损坏记录保护，以及以下 schema 2 行为：

- 元数据历史使用轻量 JSON，相同完整内容不重复创建 RTFD 文件。
- schema 1 经完整核验后迁移，原始内嵌记录快照保留；迁移失败时原记录不改变。
- 内容文件缺失、损坏时，读取不发布半份资料，保存拒绝覆盖。
- 缺失或损坏的内容文件修复后，当前内存修改可重试保存。

Flat RTFD 去重以完整正文包为单位；不同正文版本仍各自保留内嵌附件，不声称逐附件独立去重。测试结果不代表实际 GUI 中文输入法或最终发行包已验收。
