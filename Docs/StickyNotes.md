# 本地便笺

V1.01 / build 2 新增便笺中心和桌面便条。参考 macOS [便笺使用手册](https://support.apple.com/zh-cn/guide/stickies/welcome/mac)，集中管理、搜索、分组与回收站为本应用补充的功能。

V1.02 起可点击便笺中心顶部左侧的“返回首页”按钮。即使已有打开文件也会回到首页；标签与未保存编辑继续保留，点击文件标签即可继续。

从侧边栏或工具栏打开便笺中心（⌘2）；⇧⌘N 创建独立桌面便笺。可编辑标题、分组、六种颜色和富文本，拖入或粘贴图片/PDF 附件，设置字体、粗斜体、下划线、删除线和列表。桌面便笺支持置顶、半透明、收起、排列及位置/尺寸恢复。关闭只隐藏；删除移入回收站，恢复后仍保留正文、格式和附件。

便笺资料保存在内部资料路径的 `StickyNotes` 子目录。存储格式为 schema 2：`notes.json` 保存标题、分组、颜色、日期、窗口状态、正文索引、默认样式和内容摘要，正文数据字段为空；完整富文本及内嵌附件作为不可变 Flat RTFD 文件存于 `Contents/<SHA256>.rtfd`。相同完整内容共用同一份文件，仅改变标题、颜色或窗口位置时不会重复保存图文包。

覆盖主记录前将原记录保存到 `History`，读回校验后原子写入新记录并再次核验。历史 JSON 引用当时的内容文件；旧内容文件和历史不自动删除，回收站资料也保留。正文发生改变会生成新的完整 RTFD 包，包内附件随该正文版本保留；本版不对不同正文版本里的单个附件另做独立去重。导出覆盖已有目标时，原目标快照保存在 `History/Exports`。

读入 schema 1 的内嵌富文本旧记录时，先核验全部记录、正文和附件，再保留原始主记录快照并迁移为 schema 2。记录、摘要、当前引用的内容文件或附件未通过核验时，不发布半份资料，也不按空便笺覆盖。会话期间内容文件被外部删除、损坏或改为符号链接时，保存会中止，不从内存静默补造缺失文件。保存失败保留内存修改并显示错误，关闭或退出前须成功保存；可以保留窗口并导出副本，修复资料后重试。正文与元数据修改在停止输入约 450 毫秒后自动保存。

导入支持 TXT、RTF 与 RTFD；系统便笺中的现有资料需先由用户在原软件导出，再导入，应用不会自动读取其私人数据库。RTFD 可完整保留富文本及附件；带附件时拒绝导出 RTF，避免丢失附件。TXT 和 Markdown 是文字副本，使用前会说明格式/附件不会转入这些副本，原便笺保持不变。

“设为新便笺默认样式”仅提取颜色、字体、字号和窗口尺寸，不复制当前正文或附件。桌面浮窗从未连接的显示器位置恢复时会移回可见屏幕。系统便笺的自定义颜色、所有排列选项、打印、系统服务等并未逐项复刻；本版本优先提供可靠的本地记录、整理与保存。

安装安全备份与工作区备份包含便笺主记录、全部内容文件和内嵌附件、历史及回收站资料。公开仓库和 Release 不包含用户的便笺资料或安全备份；应用的资料路径沿用原版本，其他文档和钥匙串凭据不迁移。
