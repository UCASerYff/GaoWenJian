# 搞文件 V1.04

搞文件聚焦 LaTeX、Markdown 写作与编译，保留两者 V1.03 的现有内核。

- 首页重新分层：主要区域是 LaTeX、Markdown，接着是 PDF 编辑器、Office 查看器，便笺放入附加工具。
- 全局工具栏与侧栏增加首页入口，⌘1 返回首页；打开标签与未保存编辑继续保留。
- PDF 增加插入图片、调整对象位置与尺寸，完善插入文字和样式设置；保留原有批注、表单、页面整理、撤销与原件备份。
- Word、Excel、PowerPoint 改为只读查看，移除新建、编辑与保存入口，系统格式登记同步改为查看器。旧版 Office 恢复稿继续保留，可查看并导出副本。
- 便笺保留已有功能与资料，作为附加工具使用。

版本 **1.04 / build 5**。适用于 Apple Silicon、macOS 14 及以上；本地签名，未进行 Apple 公证。
PDF 的文字/图片编辑为叠加对象，不提供原文重排、OCR 或安全涂黑。Office 版式预览由 macOS 提供，具体文件效果受系统格式支持影响。

Release 提供 DMG 和 SHA256 校验文件。只发布程序、源码、资源与许可，不包含个人文件、便笺、附件、设置或安全备份。
