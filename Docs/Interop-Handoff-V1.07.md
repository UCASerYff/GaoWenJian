# 文档交接契约与待验收条件

本文区分本应用实现、提供方接口与实际界面验收。无窗口测试通过，不表示本人确认、窗口焦点、权限面板或跨 App 往返已经验收。默认不自动启动应用或冒烟窗口。

## 搞研究导入与编辑返回

本次只读核对的已安装搞研究为 V4.03 / build 4，bundle ID 为 `com.academic-achievement.manager`。其 V4.03 实际校验器要求文件路径使用 `payload/文件名`；搞文件对研究导入请求显式采用这一兼容路径，实际文件仍只有一份 `payload` 内容，OCR 与结果包的默认路径保持不变。来源摘要和固定描述符校验继续执行。其能力表公开 `research.importDocuments`，输入为文件副本，必须由搞研究再次确认导入；可选 `targetRecordID` 不能由外部请求编号猜测。本应用“将当前文档副本交给搞研究”是新的导入请求，不表示替换原附件，也不表示当前编辑器已经保存。

搞研究的外部编辑使用 `documents.open` 请求：本应用经本人确认后打开校验副本，保留原输入摘要和请求来源信息；当前修改不覆盖研究原附件。返回处理状态沿用原 `action`、原请求 `inReplyTo` 和原来源目标，`workflowState=opened`、`saved=false` 只表示打开。来源 bundle ID 是未经身份认证的声明，既不授予读取权限，也不授予回写权限。

当前搞研究仅接受不含附件或引用的 `documents.open` 状态结果，并明确拒绝把结果附件当作保存稿导入。因此兼容的编辑回收流程为：

1. 在搞研究原文档上发起搞文件编辑，本人在搞文件确认收到的副本。
2. 编辑完成后在搞文件选择“导出编辑副本…”，文字导出当前 UTF-8 内容；PDF 明确选择当前修改或已保存版本。导出使用真实当前 PDF 模型并提交表单焦点，不读取延迟恢复稿来猜测最新版本。
3. 在保存面板选择新文件；若选择已有目标，重新确认目标摘要并保留快照。最初入站副本、当前标签原路径及其同源链接不得作为导出目标。导出不清除 dirty、撤销或恢复状态。
4. 回搞研究原条目选择“导入编辑新版本…”，本人重新选择保存的编辑副本，再选择新版本或新附件。研究端负责核对原附件版本与摘要、保留历史及提交事务。

本应用不会自动启动搞研究，不会通过一份普通 `research.importDocuments` 请求伪装成原附件更新，不会在 `documents.open` 的结果中夹带编辑附件。普通只读 Office/图片等格式仅按字节导出已保存内容；无法无损导出的旧格式未保存稿明确拒绝并保留恢复稿。LaTeX 源码导出保留 `.tex` 等原扩展名，无须适配研究导入格式。

自动返回编辑稿仍需搞研究配合增加能力。建议共同确认版本化能力声明、原请求与原 sourceItemID/sourceSHA256 映射、返回输出 ID/摘要/版本、接收端明确的新版本/新附件审批、原记录并发变化和重复提交收据，再实现双方测试。不应私自扩展现有 `documents.open` 的零附件结果语义。

## 搞整理 files.choose

本次未发现已安装搞整理提供方。实际应用选择、取消、撤权及失效目标往返未验收，不能报告为真实跨 App 完成。

未来提供方应公开 GaoAction V1 的 `files.choose` 参数 schema，保持本地选择意图，返回 `kind=file` 引用与原 `inReplyTo`。目标 `com.gaoseries.GaoZhengLi` 和来源 bundle ID 仅用于能力/流程匹配，不是身份认证或安全作用域授权。消费者不能读取提供方索引或数据库。

接收端应逐项展示选择原件或校验副本，由本端系统面板重新取得读取权限；默认使用副本。选择原件须明确说明以后保存会修改该文件，并遵守当前编辑器的摘要冲突和历史快照保护。当前已打开且含未保存内容的同一路径标签不得被外部选择重置。

重新选择后必须核对规范路径、设备/inode、大小、修改时间和可用摘要。目标移动、删除、内容或身份变化时停止，说明原引用失效并要求重新选择/由提供方重发；不把同名新文件当成同一原件。仅取消面板不会授予访问权限；全部取消、部分打开、不可读和目标失效应分别呈现。每项系统访问作用域仅在本次读取期间持有并成对释放。重复或中断结果不得静默重放、覆盖或丢掉已打开内容。

## 验证边界

本应用的定向无窗口测试可覆盖生产 prepare/receive/export 路径、真实内存模型、原件/副本摘要、去重和失败状态；它不能替代真实表单输入焦点、保存面板、NSWorkspace 路由或研究端本人复核。专项 GUI 和实际跨 App 验收应在用户明确授权后使用隔离资料进行，并逐项记录取消、部分失败、撤权、目标失效、摘要不变与新标签状态；尚未实际执行的项目一律标为未验收。
