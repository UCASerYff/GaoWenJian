# 搞文件 V1.11 / build 12

本版重新设计主界面，并移除备份功能。文档格式、Bundle ID、现用资料路径和固定 Apple Development 签名身份保持不变。

- 工作台采用暖白与深石墨配色，随系统外观切换；森林绿为主要强调色。
- LaTeX 与 Markdown 写作入口优先展示。PDF 编辑与 OCR 同组，Office 查看合并为一个入口，最近文件按窗口宽度显示在右侧或下方。
- 文件整理取消第二侧栏，改用顶部的查找、收藏、授权目录、工作区和整理计划入口。切换模块保留编辑器实例与未保存内容。
- 移除保存前历史快照、便笺历史与导出快照、工作区 ZIP 备份、整理核验备份及 Office previous 自动副本。
- 便笺保存成功后，仅清理已核验且不再被现用或回收站记录引用的旧正文；现用附件、恢复稿、整理业务历史和迁移权威继续保留。外部修改冲突仍阻止覆盖。
- 安装只读核对现用资料与设置摘要；核验候选后卸载旧程序，不保留备份或回滚副本。构建和安装暂存在私有 `.noindex` 目录，用后清理。
- 公开源码与安装包不包含用户资料、便笺、附件、设置、凭据或私有验证记录。

采用固定 Apple Development 身份逐组件签名，未公证。默认不运行冒烟测试，也不为验证启动应用、浏览器或测试窗口。

验证：安装与公开源码策略的 15 项单元检查通过；定向无界面回归覆盖文件保存、Office 草稿、PDF 编辑与保存、95 项安全导出检查及 17 项便笺正文/附件检查，全程 NSApp 保持为空。整理索引、30 项移动安全检查及 23 项关联/配置检查也通过，使用合成文件和系统适配器替身。未运行通用冒烟或 GUI 验收。
