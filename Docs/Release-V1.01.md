# 搞文件 V1.01

本次更新加入本地便笺中心和独立桌面便条，适用于 Apple Silicon、macOS 14 及以上。版本 1.01，构建 2。

- 富文本、字体样式、列表、图片和 PDF 附件，正文自动保存。
- 六种颜色、置顶、半透明、折叠、桌面排列及窗口位置恢复。
- 标题与正文搜索、分组、排序、回收站和恢复。
- TXT / RTF / RTFD 导入导出；含附件的完整副本使用 RTFD。可将文字送入 Markdown 工作台，附件在 Markdown 中显示名称标注。
- 完整富文本包按内容去重保存，历史记录引用已核验的正文包，避免窗口或颜色变化重复复制附件。修改正文仍保留新的完整正文包。
- 损坏或缺失资料、附件和外部修改阻止覆盖；保存失败保留修改，并阻止关闭或退出。

原有 Markdown、LaTeX、PDF 和 Office 基础编辑继续保留。账户、联网同步及 AI 功能暂不开发。系统便笺的现有资料请从原软件导出后手动导入，应用不会自动读取其私人数据库。

下载 DMG 及对应 SHA256 校验文件。当前采用本地签名，未进行 Apple 公证。发行包和源码不包含个人文档、便笺、附件、设置或安全备份；第三方组件许可及对应源材料随源码和应用提供。
