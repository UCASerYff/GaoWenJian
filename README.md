# 搞文件 V1.06

以 LaTeX、Markdown 写作与编译为核心的 macOS 本地工作台，适用于 Apple Silicon、macOS 14 及以上。当前版本 **1.06 / build 7**，初始版本为 1.00。账户、联网同步和 AI 功能暂不开发。

| 文件 | 当前可用能力 |
| --- | --- |
| Markdown | 即时块编辑、源码/分屏、大纲、表格、任务、脚注、公式、Mermaid、代码高亮、本地图片、HTML/PDF 导出 |
| LaTeX | 智能主文件与 `% !TeX root = ...` 识别、章节/插图/表格/标签/文献大纲导航、命令/环境/标签/文献智能补全；结构化诊断与错误点击跳转；SyncTeX 源码与 PDF 双向定位（正向定位/⌘-点击反向定位）；增强型 PDF 缩放、快捷公式与环境工具栏；内置 Tectonic 离线编译与本机 XeLaTeX/pdfLaTeX/LuaLaTeX 引擎支持 |
| PDF 编辑器 | 阅读、搜索、目录、缩略图、双页；插入文字与图片、批注、表单；调整插入对象的位置与尺寸；页面旋转、裁剪、排序、删除、合并、提取、拆分；撤销与保存；提供“识别扫描件 (OCR)”交接入口 |
| Word / Excel / PPT 查看器 | 只读版式预览，现代 Office 文档另有内容阅读模式；不提供新建、编辑或覆盖保存；旧版未保存草稿保留并可导出副本 |
| CSV / TSV | 源码/表格、筛选、排序、增行列、复制为 Markdown 表格，支持引号、换行及前导零 |
| RTF / 文本 / 图片 | 富文本编辑与字体；文本编辑和查找；图片缩放查看与图片文字识别入口 |
| 跨应用交接 (GaoAction V1) | 提供 `documents.open` 与 `documents.newText`；匹配 `ocr.files` 原动作结果，文字进入新未保存标签，PDF 打开新副本并核对来源；接收搞整理用户所选文档；把当前文档副本交给搞研究复核导入 |
| 附加便笺 | 富文本和图片/PDF 附件、六色、分组/搜索、自动保存、回收站恢复、TXT/RTF/RTFD 导入导出；独立桌面窗口、置顶、半透明、折叠、排列及位置恢复；支持顶部一键返回首页 |

首页按“写作与编译 → PDF 编辑器 → Office 查看 → 附加工具”排列，LaTeX、Markdown 为主要入口。侧栏与工具栏可随时返回首页，保留已打开的文件与未保存编辑。

采用原生窗口、标签页、文件夹浏览、最近文件与独立设置窗口。用户文档保留原路径，覆盖前留存并校验原件快照；外部修改或删除会阻止覆盖。文本、PDF、RTF 有本地恢复机制，旧 Office 恢复稿继续保留；损坏草稿保留并报错。

V1.06 修复并补全文档交接的实际处理链：

- OCR 由“搞截图”在本机执行。发送前复制本次明确选择的文件，记录请求、每份输入摘要和私有来源版本；返回结果保留 `ocr.files` 原动作，通过 `inReplyTo` 与逐项来源摘要匹配。来源 bundleID 只是声明，不是身份认证。
- `documents.newText` 与 OCR 文字结果均进入新的未保存标签；保留当前编辑、草稿和便笺。PDF 结果打开新副本，保留原件。有可靠 PDF 来源时核对页数、旋转、MediaBox/CropBox 与文字层；来源不足时明确限制，不宣称已完成完整对照。
- 发送未保存 PDF 时，明确选择当前编辑副本或磁盘已保存版本。当前副本读取实际编辑器模型并先提交表单输入，避免依赖延迟恢复稿；发送不会保存或覆盖原件。
- “交给搞研究”发送当前标签的文档副本，文字使用当前编辑内容；PDF 按用户选择导出版本。搞研究需独立复核并导入。LaTeX 源码经明确确认后发送保留 `.tex.txt` 文件名的 UTF-8 文本副本；若需排版结果，请先编译并打开 PDF 后发送。未支持的非文本格式会拒绝发送。打开请求成功只表示交接已发出，对方状态也不表示当前编辑器已保存。
- 未检测到兼容提供方时，可以导出文档副本或在 Finder 显示交接包。多文件可导出到所选目录；已有目标需要重新确认摘要、保留快照后提交，目标与源/受保护原件相同时拒绝导出。失败不先删除目标。
- 接收搞整理 `files.choose` 结果时，只处理结果列出的文件，仍由本端选择并核对读取权限；不读取对方索引库。能力发现兼容 V1 的动作数组和动作字典表示，并核对实际安装版本及参数声明。
- `pending`、`partial`、`failed`、`cancelled` 与完成分别记录。重复结果不重复打开，中途执行崩溃后保留中断记录，不自动重放。交接日志或来源副本损坏、丢失、过新或发生冲突时停止处理。

所有交接都使用固定 GaoAction V1 包；项目数、字节数、正文和路径均受限制。正文、图片、原路径不会放入 URL 查询、公共剪贴板或运行日志。敏感应用资料、钥匙串、设置和安全备份不能作为交接输入。缺少提供方时的本地导出可独立使用；实际应用之间的窗口与用户交互往返须另行验收。

V1.04 重新梳理首页和导航，Office 改为只读查看，PDF 增加插图与对象调整。LaTeX、Markdown 的编辑与编译内核保持 V1.03 原样。

V1.03 全面升级 LaTeX 模块：支持魔术注释 `% !TeX root = ...` 自动识别主文件；左侧折叠面板提供篇、章、节、子节及插图、表格、标签与文献大纲，点击即时跳转行；支持命令、环境（自动配对闭合）、标签与文献补全；编译日志结构化诊断卡片并支持点击跳转出错行；支持 SyncTeX 正向与 ⌘-点击反向双向定位；PDF 预览增加缩放与快捷公式工具栏。

V1.02 在便笺中心顶部加入“返回首页”按钮。返回首页会保留已经打开的文件标签和未保存编辑，点击原标签即可继续。

V1.01 新增便笺中心与桌面便条，参考本机 macOS 便笺的使用方式，并补充集中搜索、分组、回收站和保存冲突保护。正文和附件保存在内部 `StickyNotes` 目录；关闭浮窗仅隐藏，删除移入回收站，不永久清空。支持将文字送入 Markdown 编辑器，原便笺继续保留；附件和完整富文本请导出 RTFD。不会自动读取或迁移系统便笺私人资料；需要迁移时先从系统便笺导出，再手动导入。详见 [便笺说明](Docs/StickyNotes.md)。

Office 版式预览取决于 macOS 对具体格式的支持；内容阅读模式不复刻完整排版。不支持的文件可交给本机办公软件打开。PDF 支持叠加文字和图片，并可调整新增对象；原始页面不栅格化。支持 PNG/JPEG/HEIC/TIFF（单张不超过 64 MB、8000 万像素）。不提供原有正文或内嵌图片直接改写、原文重排、OCR 或安全涂黑。涉及账户或联网的协作与同步暂不包含。不要把现有基础能力理解为完整 Microsoft Office、Typora 或 Overleaf 的等价替代。

具体范围见 [OfficeSupport](Docs/OfficeSupport.md)、[MarkdownDependencies](Docs/MarkdownDependencies.md)、[RTFRecovery](Docs/RTFRecovery.md)。

## 安装与运行

安装包在 `Release/GaoWenJian-1.06.dmg`，也可从 [GitHub Releases](https://github.com/UCASerYff/GaoWenJian/releases) 下载。打开后将“搞文件”拖入 Applications。当前版本采用本地签名，未公证。默认安装位置 `/Applications/搞文件.app`。

快捷键：⌘1 首页、⌘O 打开、⌘N 新 Markdown、⇧⌘N 新桌面便笺、⌘2 便笺中心、⌘S 保存、⇧⌘S 文本另存 UTF-8、⌘F 文本查找、⌘B 当前 LaTeX 编译、⌘W 关闭当前标签或浮窗、⌘, 设置。

默认内部资料路径：`~/Library/Application Support/GaoSeries/GaoWenJian`。原件在用户选择的位置；设置“导出工作区备份”不包含目录外的文档原件，需要一起备份项目文件夹。安装安全备份另保存在本项目 `安全备份` 中，不随升级删除，不上传。

## 构建与验证

需要 Xcode 命令行工具。所有运行时 Web 依赖、Tectonic 和基础宏包已随资源提供，应用不联网获取依赖。

```sh
python3 Tests/InstallTests.py
Scripts/test-headless.sh
Scripts/build.sh
```

开发默认只按改动执行静态、编译或针对性单元/非 GUI 集成检查，不自动执行冒烟测试，也不为验证启动 App、浏览器或测试窗口。`Scripts/test.sh` 保留完整历史回归，其中含原生界面对象测试，需明确选择后使用。当前版本的验证范围见 [V1.06 验证记录](Docs/Verification-V1.06.md)。

`test-headless.sh` 使用临时资料副本并检查 `NSApp == nil`。可选 `--ocr-provider` 参数用于调用以提供方原始生产方法编译的无 GUI CLI；未提供时不声称运行了真实 OCR 后端往返。`--verify-data-copy` 只在新临时目录中核验指定备份的副本。

构建临时目录自动清理。`Scripts/build.sh --app-only /private/tmp/新的测试程序.app` 可生成隔离测试 App；`--data-dir /private/tmp/隔离资料` 指定测试资料位置；`--show-notes` 直接显示便笺中心。

安全安装：

```sh
Scripts/install.sh --app /绝对路径/搞文件.app --defer-cleanup
Scripts/finalize-install.sh --manifest /返回的绝对路径/manifest.json --verified
# 验收失败：退出新程序后用 --rollback 代替 --verified
```

先备份并逐文件核验本应用资料和设置（含便笺格式及全部附件），再安装并核对程序、签名和资料保留结果，最后按实际验证记录确认并删除旧程序。冒烟测试和应用窗口操作只在用户明确要求时进行，未运行的项目须如实列出。后续正式版本每次 **+0.01**、构建号 **+1**。只保留最新本地发行包、源码、用户资料及安全备份；只处理本应用系统登记。
