搞文件 V1.03

把本地文档集中在一个工作台编辑。无需账户，暂不提供联网同步或 AI。

开始：打开文件、打开文件夹，或从首页进入便笺中心、新建 Markdown、LaTeX、Word、Excel、PPT。
⌘O 打开，⌘N 新 Markdown，⌘S 保存，⇧⌘S 文本另存 UTF-8，⌘F 查找，⌘B 编译当前 LaTeX，⌘W 关闭标签，⌘, 设置。

便笺：顶部“返回首页”按钮可以回到首页，已打开文件与未保存编辑保留，点击原标签继续。⌘2 打开便笺中心，⇧⌘N 新建桌面便笺。支持六色、富文本、字体、列表和图片/PDF 附件，自动保存到本机；可搜索、分组、设置默认样式、导入导出。桌面便条可置顶、半透明、折叠和排列，关闭只隐藏；删除移入回收站，可恢复。带附件请导出 RTFD；送到 Markdown 的是文字副本，原便笺与附件保留。系统便笺资料不自动迁移，可从原软件导出 TXT/RTF/RTFD 后手动导入。保存冲突或损坏资料会保留并报错，不能空白覆盖。

Markdown：点击段落进入块源码编辑，点击别处完成渲染；可切换源码和分屏。支持公式、图示、表格、任务、大纲、本地图片。先保存文档再插入图片。导出 HTML/PDF 使用本地资源。

LaTeX：支持魔术注释 % !TeX root = ... 自动识别主文件；左侧折叠面板提供篇、章、节、子节及插图、表格、标签与文献大纲，点击即时跳转行；支持命令、环境（自动配对闭合）、标签与文献补全；编译日志结构化诊断卡片并支持点击跳转出错行；支持 SyncTeX 正向与 ⌘-点击反向双向定位；PDF 预览增加缩放与快捷公式工具栏。内置 Tectonic 离线编译，亦兼容本机 XeLaTeX/pdfLaTeX/LuaLaTeX。实时预览与一键导出 PDF。

PDF：搜索文字、批注、填写表单，整理/合并/提取/拆分页面。添加文字与便签后点击页面放置。加密 PDF 解锁后只读；已有签名的文件建议另存副本。原文重排、OCR、安全涂黑暂不提供。

Office：原生编辑为基础功能。Word 编辑正文段落/已有样式；Excel 编辑单元格/支持的公式/工作表；PPT 编辑文本框/页面/位置尺寸。复杂对象不完整显示，请用本机 LibreOffice 检查完整版式并导出 PDF。旧 doc/xls/ppt 可转换为新格式后编辑。高级功能和公式兼容范围见应用资源 Docs/OfficeSupport.md。

保存：原文件保留原来的位置，覆盖前自动创建并读回校验历史快照。其他程序修改或删除原件时，会阻止覆盖，请重新打开或另存副本。文本、PDF、Office、RTF 的恢复草稿不会直接改动原件；恢复后检查再保存。选择“不保存”关闭会丢弃有效活动草稿，损坏或有冲突的恢复资料继续保留。

内部资料：~/Library/Application Support/GaoSeries/GaoWenJian
设置中的工作区备份包含恢复草稿、工作区记录与历史；外部文档和附件请随原项目文件夹一起备份。

安装：打开 DMG，将搞文件拖入 Applications。本版要求 Apple Silicon / macOS 14+，使用本地签名。
源码、最新版安装包与安全备份保存在桌面“搞app/搞文件”。正式更新每次版本加 0.01、构建号加 1，验证成功后清理旧程序和中间构建。本轮已批准发布公开 GitHub 仓库：github.com/UCASerYff/GaoWenJian。仅上传程序、源码、资源与许可，不上传个人资料、便笺、附件、设置、备份或凭据。
